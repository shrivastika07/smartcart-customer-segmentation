# SmartCart Customer Analysis

This project analyzes SmartCart customer data using Python and Machine Learning techniques.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project

The project includes data preprocessing, exploratory data analysis, and customer segmentation using clustering techniques.

## Files

- `smartcart_customer.ipynb` — Main Jupyter Notebook
- `README.md` — Project documentation
